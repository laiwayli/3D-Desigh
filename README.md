# Planform 智構

繁體中文的互動式住宅平面設計原型，使用 React、TypeScript、SVG 與 Three.js。從 2D 配置開始，選定方案後可直接查看同一份資料產生的 3D 空間。

## 直接開啟可攜版

下載 `dist-standalone/Planform.html` 到電腦，以 Chrome 或 Edge 開啟即可，不需要 Node.js 或網站伺服器，PDF 讀取程式與 worker 也已內嵌。聊天附件的預覽器可能不執行 JavaScript，請先下載；手機檔案預覽器也可能限制執行，建議使用電腦版瀏覽器。可攜版使用系統字型。

開發者可用 `npm run test:standalone` 重新建置、驗證並產出可攜檔案。`npm run package:download` 會再用 Python 3 打包 ZIP 至 `downloads/Planform.zip`。離線驗證會在隔離頁面載入完整 HTML，拒絕其他網路請求，檢查家具編輯、入口配置、3D、JSON 匯出、離線 PDF 選頁與尺寸校正。本雲端瀏覽器的管理政策禁止 `file://`，所以直接從檔案開啟尚未在此機器驗證。

此雲端環境設定介面不提供使用者可開啟的網站預覽，環境內啟動開發伺服器不等於對外發布網站。環境重啟後，開發伺服器也需重新啟動。

## 開始使用

需要 Node.js 22.13 以上（本環境使用 24）與 npm。

```bash
cd /workspace/3D-Desigh
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev -- --port 5173
```

正式建置與本機預覽：

```bash
npm run build
npm run preview
```

字型隨 npm 套件一起安裝，應用程式執行時不需要連線到外部字型或 API 服務。不需要 API 金鑰、資料庫或登入。

## 已實作

- **2D 圖面**：外牆尺寸與厚度、外牆鎖定與就近解鎖按鈕、尺寸標註、牆體剖面線與 100 mm 格點。
- **原圖匯入**：PNG／JPG／WebP 圖片及 PDF（選取頁面）作為半透明底圖。PDF 的可讀取數值標註供核對，圖面只在瀏覽器處理，不上傳外部服務。
- **尺寸校正**：點選同一尺寸線兩端，輸入原圖標註值，支援 mm／cm／m。已校正底圖保留實際比例，不因外牆調整而拉伸。可移動、隱藏、調整透明度或移除底圖。
- **精確長寬**：空間設定旁點「解鎖調整」，輸入 2–60 m 的長寬（支援小數三位），再按「套用長寬」。輸入中途不變更配置；按鈕套用後調整隔間與家具位置；超過新空間範圍的家具可能縮放，請再次核對實際家具尺寸。
- **隔間編輯**：點選起點／終點畫牆，支援水平與垂直吸附；按住 Shift 可自由角度繪製。選取牆面後可拖曳整面牆、拖曳端點、精確輸入牆長、調整厚度或刪除。
- **CAD 風格家具**：10 類 SVG 圖塊，可加入、拖曳、旋轉、調整尺寸、複製與刪除。家具外框會限制在建築邊界內。
- **入口連動配置**：三套規則範本，可選左／上／右／下入口；隔間與家具隨方向一起變換，保留矩形外牆尺寸、牆厚及層高。
- **方案比較**：最多保留 12 個方案，可載入、刪除與轉成 3D。編輯支援 50 步復原／重做。
- **3D 預覽**：從相同牆面與家具資料建立 WebGL 模型，支援旋轉、平移、縮放、剖切與完整層高檢視。北歐簡約白系搭配淺木紋地板、米白軟裝、奶茶色、暖光、收納櫃與空間標籤；為即時設計示意。
- **資料保存**：自動保存至瀏覽器 localStorage；可匯出 SVG 向量平面圖及 JSON 備份，也可從「方案」載入 JSON。
- **響應式介面**：桌面雙側面板，手機可展開工具與使用物件浮動操作列。

快速鍵：`V` 選取、`H` 平移、`W` 畫牆、`R` 旋轉家具、`Delete` 刪除、`Ctrl/⌘ Z` 復原、`Ctrl/⌘ Shift Z` 重做、`Esc` 取消。

## 驗證

```bash
npm test
npm run test:e2e
```

Vitest 驗證配置變換、固定外牆、入口開口、家具邊界與備份資料驗證。Playwright 驗證長寬編輯、PNG 匯入、PDF 選頁、標註尺寸校正、無效檔案處理、畫牆／拖牆／端點編輯、家具操作、入口連動、方案保存、匯出與 JSON 載入、WebGL 3D、手機操作。

瀏覽器測試預設使用 `/usr/bin/chromium`，可透過 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定其他 Chromium 執行檔。測試會啟動 Vite；非 CI 時可重用已有的 5173 服務。

## 第一版範圍

這是可操作的概念設計工具。生成器使用三種規則範本，邊界目前為矩形（2–60 m）；未提供任意多邊形外牆或 DWG／DXF 匯入。入口可選方向，尚不可沿外牆任意拖曳。

房間名稱與面積為範本示意。手動新增、移動、縮放或刪除隔間後會清除分區估算，避免顯示過期面積；目前沒有自動封閉區域偵測。家具與牆面之間尚未自動避碰，也不檢核通道、建築法規、結構、消防與管線。

3D 家具是量體示意；2D 的窗戶目前為圖面標記，3D 未開窗。這些圖面不宜直接當作施工圖。

圖片與 PDF 匯入是底圖流程，不會自動辨識牆面或把像素轉成 3D。PNG／JPG 的尺寸數字需自行確認；PDF 的可讀數值可能包含標號，不能直接當成牆長。以清楚且較長的尺寸線校正，可降低點選誤差。輸入支援三位小數不代表測量達到毫米精度，仍應核對原圖與現場尺寸。

匯入檔案上限 15 MB，底圖會轉成最長邊不超過 2400 px 的 JPEG 以利保存。受密碼保護或含特殊字型／影像的 PDF 若無法顯示，請先轉存成 PNG／JPG。標準字型由系統提供；未內嵌的特殊 PDF 字型可能需要先轉成圖片。

資料只保存在當前瀏覽器，清除網站資料或更換裝置不會保留；重要方案請匯出 JSON。沒有後端同步或多人協作。

## 專案位置

- `src/model.ts`：配置資料、入口轉換、邊界與家具約束。
- `src/PlanCanvas.tsx`、`src/FurnitureShape.tsx`：SVG 圖面與 CAD 家具繪製。
- `src/Scene3D.tsx`、`src/nordicScene.ts`：Three.js 模型、材質、燈光及視角控制。
- `src/FloorplanImport.tsx`、`src/floorplanImport.ts`：圖片／PDF 匯入與標註尺寸校正。
- `src/UnderlayControls.tsx`、`src/WallLengthControl.tsx`：底圖與精確牆長控制。
- `src/App.tsx`：編輯操作、方案管理、保存及匯出。
- `src/styles.css`：工作室介面與響應式樣式。

Codex 雲端任務已提供隔離環境；後續工作直接使用現有 checkout，不需建立 Git worktree。
