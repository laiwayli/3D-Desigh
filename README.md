# Planform 智構

匯入平面圖、確認尺寸、辨識牆線、自動配置可修改的家具，再選擇 10 種風格查看或匯出 3D。

## 下載與操作

到 `downloads/Planform.zip` 的 GitHub 檔案頁點選 **Download raw file**，下載並解壓縮，以電腦版 Chrome 或 Edge 開啟 `Planform.html`。不需要 Node.js、伺服器或網路。聊天與手機檔案預覽器可能不執行 JavaScript，請先下載到電腦。

兩個重建入口：

1. **載入你提供的三房兩衛範例**：同一戶原始尺寸圖與海報中央 3D 的人工對照草模 v2。主體尺寸鏈採 7.76 × 10.67 m；左中原臥室（一）採上下舖兒童房，右中原臥室（二）採雙人 WFH 書房。原始房名與設計用途並列，海報右上小平面與中央 3D 用途互換的差異另有說明。右側兩個粗塊以估測柱位呈現；右下 X 區用途及邊界待核，從地板扣除並禁止自動擺家具。左上外凸陽台的寬度與曲線仍未讀清，暫未建入主體模型；左側雨遮也不當成室內。此草模用於核對，不代表完整建築外框已精準復原。
2. **匯入原圖並重建**：支援 PNG、JPG、WebP 與 PDF 選頁。先以 90° 旋轉調整方向，框選建築本體，排除尺寸線及圖例；輸入這張圖的主體寬／深／單位，再按「辨識牆面並配置家具」。預設將候選牆疊回實際底圖，可隱藏候選牆比較，也可切換家具草稿。查看線條摘要與待核項目後套用進入 3D。尺寸欄起始留空，換圖、換頁或旋轉後重新填寫，避免沿用別戶尺寸。

匯入模式也可切換成「僅匯入描圖底圖」，沿用兩點標註校正與手動描牆。

## 編輯與風格

- **尺寸與隔間**：在長寬欄位旁按「解鎖調整」，輸入 2–60 m（支援三位小數）並套用。可畫牆、拖曳牆面／端點、輸入精確牆長與厚度。已校正底圖保留實際比例；尺寸修改後請核對位置。
- **預設家具**：新增可編輯的上下舖與雙人工作桌圖塊；雙人工作位會同時檢查桌子與兩張椅子是否可放入。依客廳、餐廳、主臥、次臥、書房、廚房、衛浴等用途配置。可修改分區用途並重新配家具，也可逐件加入、拖曳、旋轉、複製、調整尺寸或刪除。
- **家具約束**：預設配置以家具外框檢查牆面、柱位、用途未知區、其他家具與外牆輪廓；放不下的物件會略過，不會為了塞入房間而縮小家具。手動編輯與舊版尺寸縮放仍需核對碰撞與實際尺寸。
- **十種風格**：北歐、日系、侘寂、現代簡約、工業、現代輕奢、奶油、鄉村、現代中式、地中海。風格會調整地板、木紋、布料、金屬、牆色、燈光與家具圓角；日系／侘寂採較低家具重心。切換不修改平面位置與尺寸。
- **3D 輸出**：可旋轉、平移、縮放、切換剖切與完整層高，並匯出目前視角的 PNG。PNG 是當前可編輯模型的實際畫面。
- **方案與備份**：50 步復原／重做、最多保留 12 個方案，自動保存於瀏覽器。SVG 匯出平面圖；JSON 包含尺寸、牆面、家具、風格、底圖及重建依據，可重新載入。

快捷鍵：`V` 選取、`H` 平移、`W` 畫牆、`R` 旋轉家具、`Delete` 刪除、`Ctrl/⌘ Z` 復原、`Ctrl/⌘ Shift Z` 重做、`Esc` 取消。

## 辨識與尺寸依據

一般圖片重建使用本機自適應對比與水平／垂直線段分析，再以封閉區域推測房間。它會分析實際匯入的像素，不會在失敗時套用無關的住宅格局。空白圖、對比不足、未找到足夠牆線或候選線過於密集時會回報失敗；不再靜默截取前 100 條而輸出誤導的模型。線條摘要反映雜訊特徵，不代表建築判讀的正確率。

這是**需要校對的線條辨識草稿**：

- 外牆以辨識範圍的矩形近似；斜牆、曲牆、陽台外推、柱、門窗與用途未知區不保證識別。
- 紙張拍攝變形、家具線、電氣符號及外圍尺寸線都可能被誤認。請先框選建築本體並檢視預覽；90° 旋轉只調整閱讀方向；正面掃描可改善結果，程式沒有自動透視校正。
- 總尺寸必須由使用者依原圖確認，沒有 OCR 自動保證標註正確。PDF 可讀數值僅供核對，可能包含標號。
- 分區用途依面積推測；開放格局或未閉合牆面可能合併房間，請修改用途或補牆後重算。
- 家具配置不檢核消防、無障礙通道、結構與管線。用途未知區與雨遮不配置家具；手動編輯後仍需核對。
- 輸入三位小數不代表照片量測達到毫米精度。來源不清楚的尺寸標為估算，核對後可標記確認；後續修改牆線會重新標為待核對。

本次範例的尺寸暫按公分解讀，保留上下兩套尺寸鏈：600＋154.5＋21.5＝776、555＋221＝776；上方 175／223.5 與下方 177.5／221 分段不同，不直接當成同一組牆心或室內淨寬。左側 349.5＋220＋165＋332.5＝1067。牆位、門洞、柱位及右下 X 區邊界仍為照片比例估測，房間範圍面積標「約」。3D 層高預設 2.8 m，可修改。模型投影扣除未知排除區後仍含牆體，不是權狀／室內淨面積。
## 模型與寫實提案圖

程式輸出是可修改的即時 WebGL 模型，不應描述為與參考海報同等的攝影級渲染。若另提供 AI 寫實提案示意，該圖片不能反向當成尺寸正確的模型，也不會取代編輯資料。兩者須分別核對。

v2 下載包的 `Same-house-v2-preview.png` 與 `Same-house-v2-plan.svg` 是本版可編輯模型的實際 3D／2D 匯出畫面，便於核對位置。幾何不明的左側外凸陽台尚未建入，請一併閱讀模型的待核說明。
圖片／PDF 上限 15 MB；底圖會轉成最長邊不超過 2400 px 的 JPEG。受密碼保護或特殊字型的 PDF 若無法繪製，請先轉存圖片。PDF.js 與官方 worker 已內嵌；不需要外部 API 或上傳圖面。

資料只保存在當前瀏覽器，清除網站資料或更換裝置不會保留；圖片與多個方案也可能超過瀏覽器容量。重要設計請匯出 JSON。

## 開發與驗證

需要 Node.js 22.13 以上（雲端使用 24）、npm；打包 ZIP 另需 Python 3。

```bash
cd /workspace/3D-Desigh
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev -- --port 5173
npm run build
npm test
npm run test:e2e
npm run package:download
```

Vitest 驗證尺寸、輪廓面積、範例重建、碰撞約束、房間偵測、陰影紙張上的線段與風格保存。Playwright 驗證尺寸編輯、圖片／PDF 匯入、旋轉像素位置、原圖疊線、密集雜訊拒絕、校正、重建草稿、空白圖失敗、10 種 3D 風格、可修改家具與 PNG／SVG／JSON 匯出。

修改範例模型後，先啟動開發服務，再執行 `node scripts/capture-reference.mjs` 重產 2D／3D 預覽並人工檢查。`npm run package:download` 建置單一 HTML，在拒絕其他網路請求的隔離頁面驗證 PDF、尺寸校正、原圖線段重建、家具與風格，再打包並驗證 `downloads/Planform.zip`。雲端瀏覽器政策禁止 `file://`，因此未在此機器直接開檔驗證。

Playwright 預設用 `/usr/bin/chromium`，可透過 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定其他 Chromium。非 CI 時可重用健康的 5173 服務。

此雲端設定介面不支援使用者直接開啟 localhost 網站。環境發布只保留檔案與設定，不等於發布網站；服務需在新任務重新啟動。使用實際 GitHub 下載網址交付檔案，不使用 `/workspace` 內部路徑。

## 主要程式

- `src/reconstructImage.ts`：匯入圖片的線段辨識與重建草稿。
- `src/referencePlan.ts`：本次平面圖的人工轉錄範例與待核對尺寸。
- `src/autoFurnish.ts`：封閉分區與預設家具約束。
- `src/interiorStyles.ts`、`src/StylePicker.tsx`：10 種材質與風格選擇。
- `src/nordicScene.ts`、`src/Scene3D.tsx`：可修改模型、風格材質、光線與 PNG 輸出。
- `src/model.ts`：資料驗證、尺寸、輪廓、底圖與重建依據。
- `src/App.tsx`：設計工作室與方案保存。

每個 Codex 雲端任務已提供隔離環境，直接使用現有 checkout；除非使用者明確要求，不建立 Git worktree。
