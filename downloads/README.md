# 可攜版下載

下載本目錄的 `Planform.zip`（在 GitHub 檔案頁點選 Download raw file），解壓縮後，以電腦版 Chrome 或 Edge 開啟 `Planform.html`。

不需要 Node.js、開發伺服器或網路。請先下載到電腦，不要在 GitHub 原始碼檢視器、聊天附件預覽器或手機檔案預覽器內執行。

本版新增：長寬旁的「解鎖調整」與「套用長寬」、PNG／JPG／WebP／多頁 PDF 匯入、依標註尺寸（mm／cm／m）做兩點比例校正、精確牆長，以及北歐白系木紋 3D。

操作順序：匯入原圖 → 點選尺寸線的兩端 → 輸入標註值與單位 → 校正 → 依底圖描牆。已校正底圖會保留實際比例；圖片不會自動轉成牆面，標註數值需使用者核對。

ZIP 包含單一 HTML 及使用說明。HTML 已在拒絕外部請求的隔離頁面驗證家具編輯、入口換向、3D、JSON 匯出，以及 PDF 匯入選頁與尺寸校正；因雲端瀏覽器政策禁止 file://，尚未在此機器直接開檔驗證。

重要方案請使用 JSON 匯出備份。
