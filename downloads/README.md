# 下載 Planform 智構

下載 `Planform.zip`（GitHub 檔案頁點 **Download raw file**），解壓縮後以電腦版 Chrome 或 Edge 開啟 `Planform.html`。不需 Node.js、伺服器或網路。

本版新增兩個入口：**載入你提供的三房兩衛範例**（主體 7.76 × 10.67 m，人工轉錄且部分尺寸待核），或 **匯入原圖並重建**（本機牆線辨識草稿，需確認主體尺寸與範圍）。重建後可自動配置家具，再逐件修改。

可選北歐、日系、侘寂、現代簡約、工業、現代輕奢、奶油、鄉村、現代中式與地中海 10 種風格，保留格局及家具位置。3D 可匯出 PNG，JSON 可完整備份設計。

包內另附 `Nordic-proposal-illustration.png`：依本次原圖與風格參考產生的 AI 北歐寫實提案示意。這張圖片不是可編輯模型，不會隨程式內家具修改而自動更新，也不保證像素中的幾何與標註尺寸完全一致。

辨識草稿與即時 3D 需核對，不能宣稱已精準自動還原照片，也不是參考海報等級的寫實渲染。詳見根目錄 README。

請先下載到電腦，勿在聊天／手機檔案預覽器裡執行。離線功能已用隔離頁面驗證；本雲端政策禁止 file://，尚未直接開檔驗證。
