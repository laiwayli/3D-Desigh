# 下載 Planform 智構 v3

下載 `Planform.zip`，解壓縮後以電腦版 Chrome 或 Edge 開啟 `Planform.html`。不需 Node.js、伺服器或網路。

開啟後按「載入你提供的三房兩衛範例」載入本戶校正版 v2。若瀏覽器顯示舊版設計，這個按鈕可載入新版，並可透過「復原」找回先前配置。

本版將兩張圖視為同一戶：原始圖定位建築，海報中央 3D 提供用途與家具配置。左中原臥室（一）採上下舖兒童房，右中原臥室（二）採雙人 WFH 書房。原始房名與設計用途可逐項核對、修改與重配家具。

主體尺寸鏈採 7.76 × 10.67 m；柱位、牆位、門洞與右下 X 區邊界仍是待核估測。X 區不鋪地板、不自動配家具。左上外凸陽台寬度與曲線未讀清，暫未建入；左側雨遮不當成室內。本版是可校對的主體草模，尚非完整外框的精準重建。

要匯入另一張圖，按「匯入原圖並重建」：旋轉轉正 → 框選建築主體 → 填這張圖的總寬深和單位 → 候選牆疊原圖核對 → 套用 3D。支援 PNG/JPG/WebP/PDF。密集雜訊會要求重新框選，可切換底圖模式手動校正描牆。程式不讀房名文字，也不校正斜拍透視。

v3 新增 43 種家具、98 個尺寸款式與 9 個分類；可以搜尋、選擇常見尺寸後加入，逐件修改寬、深、高、主色及木／布／皮／石／金屬表面。桌／檯面的高度以主體為準，螢幕／鏡面／龍頭另計，吊燈依層高懸掛。可直接在 3D 點家具開啟外觀屬性，並用全屋／客廳／主臥／俯視鏡頭查看細節。

北歐、日系、侘寂、現代簡約、工業、現代輕奢、奶油、鄉村、現代中式及地中海 10 種風格，會改變實際扶手、桌腳、櫃門、燈罩與細緻表面；保留格局與家具位置。十張風格卡是同一樣板客廳的真實模型預覽。初次會逐張繪製，軟體 WebGL 或舊裝置可能需數十秒，可先選擇；重開使用快取。

附件 `Same-house-v3-preview.png`、`Living-detail-v3.png`、`Same-house-v3-plan.svg` 是模型全景／近景／平面；`Style-comparison-v3.png` 是風格樣板；`Furniture-library-v3.png` 是 43 種實際家具。它們皆由程式模型實際繪製，仍屬即時設計模型，尚非參考海報等級的照片級渲染。尺寸鏈不能直接當成淨尺寸，模型面積含牆體，請核對後再用於設計。

3D 可匯出 PNG，JSON 可備份尺寸、家具外觀、風格與圖面依據。資料仍保存在瀏覽器；重要方案請匯出JSON，舊專案可直接載入。

請先下載到電腦，勿在聊天／手機檔案預覽器裡執行。離線功能以隔離頁面驗證；雲端政策禁止 file://，尚未在這台雲端機器直接開檔驗證。
